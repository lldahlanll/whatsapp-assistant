## Prerequisites

- **Python 3.12** (disarankan sama dengan versi image Docker: `python:3.12-slim`)
- Redis dan konfigurasi environment sesuai dokumentasi deploy Anda

```bash
python3.12 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
